# MAC 주소
- Media Access Control 의 줄임말로 2계층에서 통신을 위해 네트워크 인터페이스에 할당하는 고유 식별자

# MAC 주소 체계
- MAC 주소는 하드웨어에 고정되어 출하됨
- 매번 할당 여부를 확인할 수 없으므로 한 제조업체에 하나 이상의 주소 풀을 주고 그 풀 안에서 각 제조업체가 자체적으로 MAC 주소를 할당
	- 제조사 코드 (Vendor Code)라고 하며 IEEE가 관리
- MAC 주소는 48비트 16진수 12자리로 표현
	- OUI (Organizational Unique Identifier) : 24bit Vendor Code. IEEE가 제조사에 할당.
	- UAA (Universally Administered Address) : 24bit. 각 제조사에서 자유롭게 할당.


## 유일하지 않은 MAC 주소
- MAC 주소는 유일하지 않을 수도 있음. 그러나 동일 네트워크에서만 중복되지 않으면 동작하는 데 문제가 없음
- OS에 따라 MAC 주소 변경 기능을 제공하는 경우도 있음
