# tcpdump

네트워크 인터페이스를 통과하는 **패킷을 실시간으로 캡처하고 분석**하는 도구. Linux/macOS 전용이며 루트 권한이 필요하다. Windows에서는 Wireshark 또는 WinDump를 사용한다.

## 설치

```bash
# Ubuntu/Debian
sudo apt install tcpdump

# macOS (보통 기본 설치됨)
brew install tcpdump
```

## 기본 사용법

```bash
sudo tcpdump [옵션] [필터 표현식]
```

## 주요 옵션

| 옵션 | 설명 | 예시 |
|------|------|------|
| `-i <인터페이스>` | 캡처할 인터페이스 지정 (기본: 첫 번째 인터페이스) | `-i eth0` |
| `-i any` | 모든 인터페이스에서 캡처 | `-i any` |
| `-n` | IP를 호스트명으로 역조회 안 함 | `-n` |
| `-nn` | IP와 포트 모두 숫자로 표시 | `-nn` |
| `-v` / `-vv` / `-vvv` | 출력 상세도 증가 | `-vv` |
| `-c <n>` | n개 패킷 캡처 후 종료 | `-c 100` |
| `-w <파일>` | 캡처 내용을 파일로 저장 (.pcap) | `-w capture.pcap` |
| `-r <파일>` | 저장된 파일 읽기 | `-r capture.pcap` |
| `-A` | 패킷 내용을 ASCII로 출력 | `-A` |
| `-X` | 패킷 내용을 HEX + ASCII로 출력 | `-X` |
| `-s <n>` | 캡처할 패킷 크기 (기본 262144, 0이면 전체) | `-s 0` |
| `-l` | 출력 버퍼링 비활성화 (파이프 사용 시 유용) | `-l` |
| `-e` | 이더넷 헤더(MAC 주소) 포함 출력 | `-e` |

## 필터 표현식

BPF(Berkeley Packet Filter) 문법을 사용한다.

### 호스트/포트 필터

```bash
# 특정 호스트와 주고받는 패킷
sudo tcpdump -nn host 8.8.8.8

# 특정 출발지
sudo tcpdump -nn src 192.168.1.10

# 특정 목적지
sudo tcpdump -nn dst 8.8.8.8

# 특정 포트
sudo tcpdump -nn port 443

# 특정 목적지 포트
sudo tcpdump -nn dst port 80
```

### 프로토콜 필터

```bash
sudo tcpdump tcp
sudo tcpdump udp
sudo tcpdump icmp
sudo tcpdump arp
```

### 조합 (and, or, not)

```bash
# 특정 호스트의 HTTP/HTTPS만
sudo tcpdump -nn host 192.168.1.5 and (port 80 or port 443)

# ICMP 제외 모든 패킷
sudo tcpdump -nn not icmp

# 특정 서브넷
sudo tcpdump -nn net 192.168.1.0/24
```

## 자주 쓰는 예시

```bash
# 웹 트래픽 실시간 확인
sudo tcpdump -nn -i eth0 port 80 or port 443

# HTTP 요청/응답 내용 보기
sudo tcpdump -nn -A -i eth0 port 80

# DNS 질의 모니터링
sudo tcpdump -nn -i any port 53

# 특정 IP의 모든 패킷 파일로 저장 (Wireshark로 분석 가능)
sudo tcpdump -nn -i eth0 -w /tmp/capture.pcap host 8.8.8.8

# SYN 패킷만 캡처 (TCP 연결 시도 모니터링)
sudo tcpdump -nn 'tcp[tcpflags] & tcp-syn != 0'

# 인터페이스 목록 확인
sudo tcpdump -D
```

## 출력 읽기

```
14:23:01.123456 IP 192.168.1.10.52341 > 8.8.8.8.53: UDP, length 29
14:23:01.124789 IP 8.8.8.8.53 > 192.168.1.10.52341: UDP, length 45
```

```
<시각>  <프로토콜>  <출발지IP>.<포트>  >  <목적지IP>.<포트>:  <프로토콜 정보>
```

- `Flags [S]`: SYN
- `Flags [S.]`: SYN-ACK (`.`은 ACK를 의미)
- `Flags [.]`: ACK
- `Flags [P.]`: PSH + ACK (데이터 전송)
- `Flags [F.]`: FIN + ACK
- `Flags [R]`: RST

## pcap 파일 분석

저장된 `.pcap` 파일은 Wireshark(GUI)로 열어 더 편리하게 분석할 수 있다.

```bash
# tcpdump로도 저장 파일 읽기 가능
sudo tcpdump -nn -r capture.pcap
sudo tcpdump -nn -r capture.pcap port 443
```
