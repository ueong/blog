# 네트워크 확인을 위한 명령어

네트워크 연결, 경로, DNS, 포트 상태 등을 진단하는 주요 명령어 모음.

## 연결 확인

| 명령어 | OS | 설치 필요 | 용도 |
|--------|-----|----------|------|
| [[202603012050 ping\|ping]] | Linux / Windows | 기본 설치 | ICMP로 연결 가능 여부 및 RTT 확인 |
| [[202603012051 tcping\|tcping]] | Linux / Windows | **설치 필요** | TCP로 포트 연결 가능 여부 및 RTT 확인 |
| [[202603012057 telnet\|telnet]] | Linux / Windows | 설치 필요 (Linux: apt, Win: 기능 활성화) | TCP 포트 연결 테스트, 텍스트 프로토콜 수동 테스트 |

## 경로 추적

| 명령어 | OS | 설치 필요 | 용도 |
|--------|-----|----------|------|
| [[202603012052 traceroute & tracert\|traceroute]] | Linux / macOS | 설치 필요 (apt) | ICMP/UDP로 목적지까지 경로 및 각 홉 지연 확인 |
| [[202603012052 traceroute & tracert\|tracert]] | Windows | 기본 설치 | ICMP로 경로 추적 (traceroute의 Windows 버전) |
| [[202603012053 tcptraceroute\|tcptraceroute]] | Linux / macOS | **설치 필요** | TCP SYN으로 경로 추적 (ICMP 차단 환경에서 유용) |

## 소켓 / 포트 상태

| 명령어 | OS | 설치 필요 | 용도 |
|--------|-----|----------|------|
| [[202603012054 netstat\|netstat]] | Linux / Windows | Linux: 설치 필요 (net-tools) | 소켓 연결 상태, 라우팅 테이블, 프로토콜 통계 |
| [[202603012055 ss\|ss]] | Linux | 기본 설치 | netstat 후속 도구, 빠르고 상세한 소켓 정보 |

## DNS 조회

| 명령어 | OS | 설치 필요 | 용도 |
|--------|-----|----------|------|
| [[202603012056 nslookup\|nslookup]] | Linux / Windows | 기본 설치 | DNS 레코드 조회, 역방향 조회 |

## 인터페이스 / IP 정보

| 명령어 | OS | 설치 필요 | 용도 |
|--------|-----|----------|------|
| [[202603012058 ipconfig & ip\|ipconfig]] | Windows | 기본 설치 | IP 주소, 게이트웨이, DNS 확인, DHCP 갱신, DNS 캐시 초기화 |
| [[202603012058 ipconfig & ip\|ip]] | Linux | 기본 설치 (iproute2) | 인터페이스 정보, 라우팅 테이블, ARP 테이블 조회 및 설정 |

## HTTP 요청

| 명령어 | OS | 설치 필요 | 용도 |
|--------|-----|----------|------|
| [[202603012100 curl & wget\|curl]] | Linux / macOS / Windows | 대부분 기본 설치 | API 호출, 요청/응답 디버깅, 다양한 프로토콜 지원 |
| [[202603012100 curl & wget\|wget]] | Linux / macOS / Windows | Linux 기본, macOS는 설치 필요 | 파일 다운로드, 이어받기, 재귀/미러링 다운로드 |

## 패킷 캡처

| 명령어 | OS | 설치 필요 | 용도 |
|--------|-----|----------|------|
| [[202603012059 tcpdump\|tcpdump]] | Linux / macOS | 설치 필요 (apt) | 실시간 패킷 캡처 및 분석, pcap 파일 저장 |
