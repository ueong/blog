# curl / wget

HTTP(S) 요청을 CLI에서 보내는 도구. 둘 다 Linux/macOS/Windows에서 사용 가능하다.

| 항목 | curl | wget |
|------|------|------|
| 주 용도 | API 호출, 다양한 프로토콜 지원, 디버깅 | 파일 다운로드, 재귀 다운로드 |
| 지원 프로토콜 | HTTP, HTTPS, FTP, SFTP, SMTP 등 다수 | HTTP, HTTPS, FTP |
| 기본 설치 | macOS 기본, Linux 대부분 기본 | Linux 대부분 기본 (macOS는 설치 필요) |
| 출력 | 기본으로 stdout에 출력 | 기본으로 파일로 저장 |

---

## curl

### 설치

```bash
# Ubuntu/Debian
sudo apt install curl

# macOS (기본 설치됨, 최신 버전은 Homebrew)
brew install curl

# Windows
# Git Bash, WSL에 포함되거나 winget으로 설치
winget install curl.curl
```

### 기본 사용법

```bash
curl <URL>
```

### 주요 옵션

| 옵션 | 설명 | 예시 |
|------|------|------|
| `-X <메서드>` | HTTP 메서드 지정 (기본 GET) | `-X POST` |
| `-H <헤더>` | 요청 헤더 추가 | `-H "Content-Type: application/json"` |
| `-d <데이터>` | 요청 바디 지정 (POST) | `-d '{"key":"value"}'` |
| `-o <파일>` | 응답을 파일로 저장 | `-o output.html` |
| `-O` | URL의 파일명으로 저장 | `-O` (URL 끝 파일명 사용) |
| `-L` | 리다이렉트 자동 따라가기 | `-L` |
| `-I` | 응답 헤더만 출력 (HEAD 요청) | `-I` |
| `-i` | 응답 헤더 + 바디 함께 출력 | `-i` |
| `-v` | 상세 출력 (요청/응답 헤더 전체) | `-v` |
| `-s` | 진행률 등 부가 출력 숨김 (silent) | `-s` |
| `-u <user:pass>` | Basic 인증 | `-u admin:1234` |
| `-k` | SSL 인증서 검증 생략 | `-k` |
| `-b <쿠키>` | 쿠키 전송 | `-b "session=abc123"` |
| `-c <파일>` | 쿠키를 파일에 저장 | `-c cookies.txt` |
| `--max-time <초>` | 전체 요청 타임아웃 | `--max-time 10` |
| `--connect-timeout <초>` | 연결 타임아웃만 지정 | `--connect-timeout 5` |
| `-x <프록시>` | 프록시 서버 지정 | `-x http://proxy:8080` |
| `--http2` | HTTP/2 강제 사용 | `--http2` |
| `-w <형식>` | 응답 후 출력할 정보 지정 | `-w "%{http_code}\n"` |

### 자주 쓰는 예시

```bash
# GET 요청 (기본)
curl https://api.example.com/users

# 응답 헤더 확인
curl -I https://example.com

# 요청/응답 전체 흐름 디버깅
curl -v https://example.com

# JSON POST 요청
curl -X POST https://api.example.com/users \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer <token>" \
  -d '{"name": "Alice", "email": "alice@example.com"}'

# 파일 다운로드 (진행률 표시)
curl -L -O https://example.com/file.tar.gz

# HTTP 상태 코드만 출력
curl -s -o /dev/null -w "%{http_code}" https://example.com

# 리다이렉트 따라가면서 최종 URL 확인
curl -s -o /dev/null -w "%{url_effective}" -L https://example.com

# 폼 데이터 전송 (multipart)
curl -X POST https://api.example.com/upload \
  -F "file=@/path/to/file.txt" \
  -F "name=test"

# SSL 인증서 오류 무시 (테스트용)
curl -k https://self-signed.example.com
```

### `-v` 출력 읽기

```
*   Trying 93.184.216.34:443...        # TCP 연결 시도
* Connected to example.com             # 연결 성공
* SSL handshake ...                    # TLS 협상
> GET / HTTP/2                         # 요청 헤더 (> 는 송신)
> Host: example.com
> User-Agent: curl/8.1.0
>
< HTTP/2 200                           # 응답 헤더 (< 는 수신)
< content-type: text/html
< content-length: 1256
<
<!doctype html>...                     # 응답 바디
```

### `-w` 유용한 변수들

```bash
curl -s -o /dev/null -w "
  http_code:        %{http_code}
  time_connect:     %{time_connect}s
  time_starttransfer: %{time_starttransfer}s
  time_total:       %{time_total}s
  size_download:    %{size_download} bytes
" https://example.com
```

## wget

### 설치

```bash
# Ubuntu/Debian (보통 기본 설치)
sudo apt install wget

# macOS (기본 없음)
brew install wget

# Windows
winget install GNU.Wget2
```

### 기본 사용법

```bash
wget <URL>
```

### 주요 옵션

| 옵션 | 설명 | 예시 |
|------|------|------|
| `-O <파일>` | 저장 파일명 지정 | `-O output.html` |
| `-P <디렉토리>` | 저장 디렉토리 지정 | `-P /tmp/downloads` |
| `-q` | 출력 숨김 (quiet) | `-q` |
| `-c` | 이어받기 (resume) | `-c` |
| `-r` | 재귀적 다운로드 | `-r` |
| `-np` | 상위 디렉토리로 올라가지 않음 (`-r`과 함께) | `-r -np` |
| `-l <깊이>` | 재귀 깊이 제한 | `-r -l 2` |
| `--mirror` | 사이트 미러링 (`-r -N -l inf --no-remove-listing`) | `--mirror` |
| `-N` | 서버 파일이 최신이면 다운로드 생략 | `-N` |
| `--limit-rate=<속도>` | 다운로드 속도 제한 | `--limit-rate=1m` |
| `--tries=<n>` | 실패 시 재시도 횟수 | `--tries=3` |
| `--timeout=<초>` | 타임아웃 | `--timeout=10` |
| `--no-check-certificate` | SSL 인증서 검증 생략 | `--no-check-certificate` |
| `-i <파일>` | URL 목록 파일에서 읽어서 다운로드 | `-i urls.txt` |
| `--user-agent=<UA>` | User-Agent 지정 | `--user-agent="Mozilla/5.0"` |
| `--header=<헤더>` | 요청 헤더 추가 | `--header="Authorization: Bearer token"` |
| `--post-data=<데이터>` | POST 요청 | `--post-data='key=value'` |

### 자주 쓰는 예시

```bash
# 파일 다운로드
wget https://example.com/file.tar.gz

# 파일명 지정해서 저장
wget -O myfile.tar.gz https://example.com/file.tar.gz

# 이어받기
wget -c https://example.com/largefile.iso

# 여러 URL 한 번에 다운로드
wget -i urls.txt

# 사이트 미러링
wget --mirror --convert-links --adjust-extension \
  --page-requisites --no-parent https://example.com

# 특정 확장자만 재귀 다운로드
wget -r -A "*.pdf" https://example.com/docs/

# 속도 제한
wget --limit-rate=500k https://example.com/bigfile.iso

# 백그라운드 실행
wget -b -o wget.log https://example.com/file.iso
```

## curl vs wget 선택 기준

| 상황 | 추천 |
|------|------|
| REST API 호출, 헤더/바디 커스터마이즈 | **curl** |
| 응답 코드/시간 등 메트릭 수집 | **curl** (`-w`) |
| 단순 파일 다운로드 | **wget** |
| 이어받기, 재귀 다운로드, 사이트 미러링 | **wget** |
| 스크립트에서 파이프 활용 | **curl** (stdout 기본 출력) |
