# tcping

ICMP 대신 **TCP 연결로 응답 여부와 응답 시간을 확인**하는 도구. ping이 ICMP 방화벽에 막혀 동작하지 않을 때 유용하다. 별도 설치가 필요하다.

## 설치

### Linux

```bash
# Ubuntu/Debian
sudo apt install tcping

# macOS (Homebrew)
brew install tcping
```

### Windows

[공식 사이트](https://elifulkerson.com/projects/tcping.exe)에서 `tcping.exe` 다운로드 후 PATH에 추가하거나 해당 디렉토리에서 실행.

## 기본 사용법

```bash
tcping <호스트> <포트>
```

```bash
tcping google.com 443
tcping 8.8.8.8 53
```

## 주요 옵션

| 옵션 | 설명 | 예시 |
|------|------|------|
| `-n <n>` | 시도 횟수 | `tcping -n 5 google.com 443` |
| `-i <초>` | 시도 간격 | `tcping -i 2 google.com 443` |
| `-t <ms>` | 연결 타임아웃(밀리초) | `tcping -t 2000 google.com 443` |
| `-4` | IPv4 강제 사용 | `tcping -4 google.com 443` |
| `-6` | IPv6 강제 사용 | `tcping -6 google.com 443` |

## 출력 예시

```
Probing 142.250.207.46:443/tcp - Port is open - time=8.23ms
Probing 142.250.207.46:443/tcp - Port is open - time=7.91ms
Probing 142.250.207.46:443/tcp - Port is open - time=8.10ms

Ping statistics for 142.250.207.46:443
  3 probes sent, 3 successful, 0 failed (0.00% fail)
  Approximate trip times: min=7.91ms, max=8.23ms, avg=8.08ms
```

> `Port is open` → TCP 3-way handshake 성공
> `Port is closed` / 타임아웃 → 해당 포트가 차단되었거나 서비스가 없음
