# telnet

원격 호스트에 **TCP 연결을 맺고 텍스트로 통신**하는 도구. 원래는 원격 쉘 접속용이었으나 암호화가 없어 SSH로 대체되었다. 현재는 주로 **특정 포트의 TCP 연결 가능 여부 확인** 용도로 사용한다.

## 설치

### Linux

```bash
# Ubuntu/Debian
sudo apt install telnet

# macOS (기본 제거됨, Homebrew로 설치)
brew install telnet
```

### Windows

기본 비활성화 상태. 활성화 필요:

```
제어판 → 프로그램 → Windows 기능 켜기/끄기 → Telnet 클라이언트 체크
```

또는 PowerShell(관리자):

```powershell
Enable-WindowsOptionalFeature -Online -FeatureName TelnetClient
```

## 기본 사용법

```bash
telnet <호스트> <포트>
```

```bash
telnet google.com 80
telnet 8.8.8.8 53
telnet smtp.gmail.com 587
```

## 포트 연결 확인 용도

연결이 성공하면 빈 화면 또는 서비스 배너가 표시된다. 연결 실패 시 `Connection refused` 또는 타임아웃이 발생한다.

```bash
$ telnet google.com 443
Trying 142.250.207.46...
Connected to google.com.       ← 연결 성공
Escape character is '^]'.

$ telnet google.com 9999
Trying 142.250.207.46...
telnet: Unable to connect to remote host: Connection refused  ← 포트 닫힘
```

## HTTP 요청 직접 테스트

텍스트 기반 프로토콜(HTTP, SMTP 등)을 손으로 입력해 테스트할 수 있다.

```bash
$ telnet example.com 80
Connected to example.com.

GET / HTTP/1.0
Host: example.com
(빈 줄 입력)
```

## 종료 방법

| 방법 | 설명 |
|------|------|
| `Ctrl + ]` 후 `quit` | telnet 프롬프트 진입 후 종료 |
| `Ctrl + C` | 강제 종료 |

## 주의

telnet은 모든 데이터를 **평문으로 전송**하므로, 실제 원격 로그인 용도로는 절대 사용하지 말 것. 연결 테스트에만 활용한다.
