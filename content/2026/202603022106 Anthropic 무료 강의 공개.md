# Anthropic 무료 온라인 강의 공개

**출처:** https://news.hada.io/topic?id=27118

## 개요

Anthropic이 Skilljar LMS를 통해 개발자부터 교육자, 학생, 비영리 재단까지 다양한 대상을 위한 무료 온라인 강의를 공개했다.

---

## 개발자 대상 과정

- **[Claude Code in Action](https://anthropic.skilljar.com/claude-code-in-action)** - Claude Code를 개발 워크플로에 통합하는 실습 과정
- **[Building with the Claude API](https://anthropic.skilljar.com/claude-with-the-anthropic-api)** - Anthropic 모델을 Claude API로 활용하는 전 과정
- **[Introduction to Model Context Protocol](https://anthropic.skilljar.com/introduction-to-model-context-protocol)** - Python으로 MCP 서버와 클라이언트를 처음부터 구축하는 방법 (tools, resources, prompts 3가지 핵심 프리미티브 포함)
- **[Model Context Protocol: Advanced Topics](https://anthropic.skilljar.com/model-context-protocol-advanced-topics)** - 프로덕션 MCP 서버 개발을 위한 고급 구현 패턴 (샘플링, 알림, 파일 시스템 접근, 트랜스포트 메커니즘)
- **[Introduction to Agent Skills](https://anthropic.skilljar.com/introduction-to-agent-skills)** - Claude Code에서 재사용 가능한 마크다운 기반 스킬을 생성·구성·공유하는 방법

---

## 일반 사용자 및 입문 과정

- **[Claude 101](https://anthropic.skilljar.com/claude-101)** - 일상 업무에 Claude 활용, 핵심 기능 이해, 고급 학습 리소스 탐색
- **[AI Fluency: Framework & Foundations](https://anthropic.skilljar.com/ai-fluency-framework-foundations)** - AI 시스템과 효과적·효율적·윤리적·안전하게 협업하는 프레임워크

---

## 교육·학생·비영리 대상 과정

- **[AI Fluency for Educators](https://anthropic.skilljar.com/ai-fluency-for-educators)** - 교수진, 교육 설계자, 교육 리더 대상
- **[AI Fluency for Students](https://anthropic.skilljar.com/ai-fluency-for-students)** - 학생들의 책임감 있는 AI 협업 역량 개발
- **[Teaching AI Fluency](https://anthropic.skilljar.com/teaching-ai-fluency)** - 학술 교수진과 교육 설계자가 강사 주도 환경에서 AI Fluency 교육·평가
- **[AI Fluency for Nonprofits](https://anthropic.skilljar.com/ai-fluency-for-nonprofits)** - 비영리 전문가의 AI 역량 개발

---

## 클라우드 플랫폼 통합 과정

- **[Claude with Amazon Bedrock](https://anthropic.skilljar.com/claude-in-amazon-bedrock)** - AWS 환경에서 Claude 활용
- **[Claude with Google Cloud's Vertex AI](https://anthropic.skilljar.com/claude-with-google-vertex)** - Google Cloud Vertex AI를 통한 Anthropic 모델 활용

---

## 학습 플랫폼 (Skilljar)

- Anthropic 계정 없이 Skilljar 계정만으로 접근 가능
- 학습 진행 상황, 레슨 완료, 퀴즈 점수, 학습 시간 등 기본 학습 분석 데이터 추적
- Skilljar 데이터는 Anthropic 계정과 별도로 관리
