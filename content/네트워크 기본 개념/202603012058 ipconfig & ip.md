# ipconfig (Windows) / ip (Linux)

**네트워크 인터페이스 정보 조회 및 설정**에 사용하는 도구. OS별로 다른 명령어를 사용한다.

| OS | 현재 표준 | 구형 (deprecated) |
|----|----------|------------------|
| Windows | `ipconfig` | - |
| Linux | `ip` | `ifconfig` (net-tools) |
| macOS | `ifconfig` | - |

---

## Windows: ipconfig

### 기본 사용법

```cmd
ipconfig           # 주요 인터페이스 정보 요약
ipconfig /all      # 전체 상세 정보 (MAC 주소, DHCP 서버 등)
```

### 주요 옵션

| 옵션 | 설명 |
|------|------|
| `/all` | MAC 주소, DHCP 서버, DNS 서버 등 상세 정보 표시 |
| `/release` | DHCP로 할당받은 IP 반납 |
| `/renew` | DHCP IP 재요청 |
| `/flushdns` | DNS 캐시 초기화 |
| `/displaydns` | 현재 DNS 캐시 내용 표시 |
| `/registerdns` | DNS 및 DHCP 임대 강제 갱신 |

```cmd
ipconfig /flushdns        # DNS 캐시 초기화 (DNS 변경 후 자주 사용)
ipconfig /release && ipconfig /renew   # IP 갱신
```

### 출력 예시

```
Windows IP Configuration

Ethernet adapter 이더넷:
   IPv4 Address. . . . . : 192.168.1.10
   Subnet Mask . . . . . : 255.255.255.0
   Default Gateway . . . : 192.168.1.1
```

## Linux: ip

`ip` 명령어는 `iproute2` 패키지에 포함되며 현대 Linux에 기본 설치되어 있다. 인터페이스 정보, 라우팅, ARP 테이블 등을 통합 관리한다.

### 기본 사용법

```bash
ip <객체> <명령>
```

### 인터페이스 정보 조회

```bash
ip addr              # 모든 인터페이스의 IP 주소 및 상태
ip addr show eth0    # 특정 인터페이스만
ip link              # 링크 계층(MAC, MTU, 상태) 정보
ip -s link           # 인터페이스별 송수신 통계
```

### 라우팅 테이블

```bash
ip route             # 라우팅 테이블 확인
ip route show        # 동일
ip route get 8.8.8.8 # 특정 IP로 가는 경로 확인
```

### ARP 테이블

```bash
ip neigh             # ARP 캐시 확인 (IP-MAC 매핑)
ip neigh flush all   # ARP 캐시 초기화
```

### 인터페이스 설정 (루트 권한 필요)

```bash
# IP 주소 추가/삭제
sudo ip addr add 192.168.1.100/24 dev eth0
sudo ip addr del 192.168.1.100/24 dev eth0

# 인터페이스 활성화/비활성화
sudo ip link set eth0 up
sudo ip link set eth0 down

# 기본 게이트웨이 추가
sudo ip route add default via 192.168.1.1
```

### 출력 예시

```
$ ip addr show eth0
2: eth0: <BROADCAST,MULTICAST,UP,LOWER_UP> mtu 1500 qdisc fq_codel state UP
    link/ether aa:bb:cc:dd:ee:ff brd ff:ff:ff:ff:ff:ff
    inet 192.168.1.10/24 brd 192.168.1.255 scope global eth0
    inet6 fe80::1/64 scope link
```

## macOS: ifconfig

```bash
ifconfig             # 모든 인터페이스 정보
ifconfig en0         # 특정 인터페이스 (Wi-Fi는 보통 en0)
```
