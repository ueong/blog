# netstat

**네트워크 연결 상태, 라우팅 테이블, 인터페이스 통계** 등을 확인하는 도구. Linux와 Windows 모두에서 사용 가능하다.

> Linux에서는 `netstat`이 deprecated 되어 `ss`로 대체되고 있다. 최신 배포판에서는 `net-tools` 패키지를 별도 설치해야 할 수도 있다.

## 설치 (Linux)

```bash
# Ubuntu/Debian (기본 설치 안 된 경우)
sudo apt install net-tools
```

Windows는 기본 설치됨.

## 기본 사용법

```bash
netstat [옵션]
```

## 주요 옵션

### Linux

| 옵션 | 설명 |
|------|------|
| `-t` | TCP 연결만 표시 |
| `-u` | UDP 연결만 표시 |
| `-l` | LISTEN 상태 소켓만 표시 |
| `-n` | 호스트명/서비스명 대신 IP/포트 번호로 표시 |
| `-p` | 각 소켓을 사용 중인 프로세스 PID와 이름 표시 (루트 권한 필요) |
| `-a` | 모든 소켓 표시 (LISTEN 포함) |
| `-r` | 라우팅 테이블 표시 |
| `-s` | 프로토콜별 통계 표시 |
| `-c` | 1초마다 갱신하며 반복 출력 |

**자주 쓰는 조합:**

```bash
# LISTEN 중인 TCP 포트 및 프로세스 확인
sudo netstat -tlnp

# 모든 TCP/UDP 연결 확인
sudo netstat -anp

# 라우팅 테이블 확인
netstat -r
```

### Windows

| 옵션 | 설명 |
|------|------|
| `-a` | 모든 연결 및 수신 대기 포트 표시 |
| `-n` | 호스트명 대신 IP/포트 번호로 표시 |
| `-o` | 각 연결의 프로세스 PID 표시 |
| `-b` | 각 연결의 실행 파일 이름 표시 (관리자 권한 필요) |
| `-p <프로토콜>` | 특정 프로토콜만 표시 (TCP, UDP, TCPv6, UDPv6) |
| `-r` | 라우팅 테이블 표시 |
| `-s` | 프로토콜별 통계 표시 |
| `-e` | 이더넷 통계 표시 |

**자주 쓰는 조합:**

```bash
# 모든 연결과 PID 표시
netstat -ano

# 특정 포트 사용 프로세스 찾기
netstat -ano | findstr :8080
```

## 출력 읽기

```
Proto  Local Address      Foreign Address    State       PID
TCP    0.0.0.0:80         0.0.0.0:0          LISTENING   1234
TCP    192.168.1.10:52341 93.184.216.34:443  ESTABLISHED 5678
```

### 주요 State 값

| State | 설명 |
|-------|------|
| `LISTEN` | 연결 대기 중 (서버 소켓) |
| `ESTABLISHED` | 연결 수립됨, 통신 중 |
| `TIME_WAIT` | 연결 종료 후 대기 (2MSL). 재사용 방지용 |
| `CLOSE_WAIT` | 상대방이 FIN을 보냄, 내 쪽 아직 종료 안 함 |
| `SYN_SENT` | 연결 요청(SYN) 전송 후 응답 대기 |
| `SYN_RECEIVED` | SYN 수신 후 SYN-ACK 전송, ACK 대기 |
| `FIN_WAIT_1/2` | 연결 종료 진행 중 |
