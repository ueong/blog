# nslookup

**DNS 레코드를 조회**하는 도구. Linux, macOS, Windows 모두에서 기본 제공된다.

> Linux에서는 `nslookup` 대신 `dig`를 권장한다. `dig`가 더 상세하고 스크립트 친화적인 출력을 제공한다.

## 기본 사용법

```bash
# 기본 A 레코드 조회
nslookup <도메인>

# 특정 DNS 서버로 조회
nslookup <도메인> <DNS서버>

# 역방향 조회 (IP → 도메인)
nslookup <IP주소>
```

```bash
nslookup google.com
nslookup google.com 8.8.8.8       # Google DNS로 조회
nslookup 93.184.216.34             # 역방향 조회
```

## 특정 레코드 타입 조회

```bash
nslookup -type=<타입> <도메인>
```

| 타입 | 예시 |
|------|------|
| A | `nslookup -type=A google.com` |
| AAAA | `nslookup -type=AAAA google.com` |
| MX | `nslookup -type=MX google.com` |
| NS | `nslookup -type=NS google.com` |
| TXT | `nslookup -type=TXT google.com` |
| CNAME | `nslookup -type=CNAME www.github.com` |
| SOA | `nslookup -type=SOA google.com` |
| ANY | `nslookup -type=ANY google.com` |

## 인터랙티브 모드

인자 없이 실행하면 인터랙티브 모드로 진입한다.

```
$ nslookup
> server 8.8.8.8         # 사용할 DNS 서버 변경
> set type=MX            # 조회 타입 변경
> google.com             # 조회 실행
> exit
```

## 출력 읽기

```
Server:         8.8.8.8        ← 질의한 DNS 서버
Address:        8.8.8.8#53     ← DNS 서버의 주소:포트

Non-authoritative answer:      ← 캐시된 응답 (권한 서버 직접 응답 아님)
Name:   google.com
Address: 142.250.207.46
```

- `Non-authoritative answer`: Resolver의 캐시에서 응답한 것. 실시간 정보가 아닐 수 있음
- 권한 있는 응답을 보려면 해당 도메인의 NS 서버로 직접 질의해야 함

## dig와 비교 (Linux 권장)

```bash
# nslookup과 동일한 조회를 dig로
dig google.com
dig google.com @8.8.8.8
dig -x 93.184.216.34        # 역방향 조회
dig MX google.com
dig +short google.com       # IP만 간단히 출력
```

`dig`는 `dnsutils` 패키지에 포함되어 있다.

```bash
sudo apt install dnsutils   # Ubuntu/Debian
brew install bind           # macOS
```
