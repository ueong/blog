# ss (Socket Statistics)

`netstat`의 후속 도구. **더 빠르고 상세한 소켓 정보**를 제공한다. Linux 전용이며 현대 배포판에 기본 설치되어 있다.

## 기본 사용법

```bash
ss [옵션]
```

## 주요 옵션

| 옵션 | 설명 |
|------|------|
| `-t` | TCP 소켓만 표시 |
| `-u` | UDP 소켓만 표시 |
| `-l` | LISTEN 상태 소켓만 표시 |
| `-a` | 모든 소켓 표시 (LISTEN 포함) |
| `-n` | 호스트명/서비스명 대신 숫자(IP/포트)로 표시 |
| `-p` | 소켓을 사용 중인 프로세스 정보 표시 |
| `-e` | 확장 소켓 정보 표시 |
| `-s` | 소켓 요약 통계 표시 |
| `-4` | IPv4 소켓만 표시 |
| `-6` | IPv6 소켓만 표시 |
| `-r` | 호스트명으로 역조회하여 표시 |

## 자주 쓰는 조합

```bash
# LISTEN 중인 TCP 포트와 프로세스 확인 (가장 자주 쓰임)
sudo ss -tlnp

# 모든 연결된 TCP 소켓
ss -tn

# 특정 포트 필터링
ss -tnp | grep :443

# 특정 원격 IP에 대한 연결 확인
ss -tn dst 8.8.8.8

# UDP 수신 대기 포트
sudo ss -ulnp

# 요약 통계
ss -s
```

## 필터 문법

`ss`는 강력한 필터 표현식을 지원한다.

```bash
# 특정 포트로 필터
ss -tn sport = :22       # 출발지 포트가 22
ss -tn dport = :443      # 목적지 포트가 443

# 특정 주소로 필터
ss -tn src 192.168.1.10
ss -tn dst 10.0.0.1

# 상태로 필터
ss -t state established
ss -t state listening
```

## 출력 읽기

```
Netid  State     Recv-Q  Send-Q  Local Address:Port    Peer Address:Port   Process
tcp    LISTEN    0       128     0.0.0.0:22            0.0.0.0:*           users:(("sshd",pid=1023,fd=3))
tcp    ESTAB     0       0       192.168.1.10:22       192.168.1.5:54321   users:(("sshd",pid=2048,fd=4))
```

- `Recv-Q`: 수신 버퍼에 쌓인 바이트 수. LISTEN에서 0이 아니면 accept 적체
- `Send-Q`: 송신 버퍼에 남은 바이트 수. 높으면 네트워크 병목 가능성

## netstat과 비교

| 항목 | netstat | ss |
|------|---------|-----|
| 속도 | 느림 (/proc 파싱) | 빠름 (커널 netlink 직접 조회) |
| 상태 | Deprecated | 현재 표준 |
| 필터 기능 | 제한적 | 풍부한 표현식 지원 |
| 가용성 | 별도 설치 필요할 수 있음 | 기본 설치 |
