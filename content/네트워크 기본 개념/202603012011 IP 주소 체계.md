IP는 3계층에서 사용하는 논리 주소. 네트워크 주소와 호스트 주소로 나누며 이 둘을 구분하는 경계점이 고정되어 있지 않고 서브넷 마스크에 따라 달라짐

네트워크 주소에 몇 옥텟을 할당했느냐에 따라 A, B, C, D 클래스로 나뉨

## 클래스풀과 클래스리스
A, B, C, D 클래스 기반의 IP 주소 체계를 클래스풀 (Classful)이라고 부름. 이 주소 체계에서는 서브넷 마스크가 필요 없음
그러나 인터넷 규모가 폭발적으로 증가하면서 IP 주소 갯수가 너무 부족했음. 그래서 여러 대책이 나옴

- 클래스리스 = CIDR (Classless Inter-Domain Routing)
	- 서브넷 마스크를 통해 네트워크를 나눠줄 수 있음
- 원래 부여된 클래스 기준을 무시하고 네트워크-호스트 구분 기준을 사용자가 정해 네트워크를 쪼개어 사용하는 것을 서브네팅 (Subnetting)이라고 함
	- 서브네팅을 할 때는 다음과 같은 사항을 고민
		- 하나의 네트워크에 IP를 몇 개나 할당해야 하는가?
		- 서브넷된 네트워크가 몇 개나 필요한가?
